# Contract-Change Records

Approved and pending shared-interface proposals and their approval history live
here. Copy `../templates/CONTRACT_CHANGE.md`, follow
`../CONTRACT_CHANGE_PROCESS.md`, and retain the record after implementation or
rejection.

`../P1-02_CONTRACT_CHANGE_PROPOSAL.md` is a legacy top-level record whose path is
retained so existing references keep working. It is approved as a manifest 1.1
design, but implementation and compatibility evidence are still pending; it is
not a statement that the runtime already accepts version 1.1.
