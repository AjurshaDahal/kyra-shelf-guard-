# Work-Item Records

Create one file per implementation/governance pull request using `../templates/WORK_ITEM.md`. Name it `WI-<issue>-<slug>.md`; use a zero-padded local ID only before a GitHub issue exists.

Work-item records preserve scope, owner, contracts, actual verification, limitations, handoff, and final links. They are retained after merge and are not a substitute for GitHub issues or tests.
